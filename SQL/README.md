# SQL Analysis

## Overview

This folder contains the SQL queries used for the **Sales & Profit Analysis Dashboard** project.

MySQL was used to explore, prepare, and analyze the sales data before using the results for visualization and reporting in Power BI.

## SQL File

### `Sales_Profit_Analysis.sql`

The SQL script contains queries for:

* Exploring the sales dataset
* Checking and validating the data
* Filtering and sorting records
* Calculating total sales and profit
* Analyzing sales and profit by region
* Analyzing product and category performance
* Analyzing customer performance
* Aggregating business metrics using `GROUP BY`
* Combining related data using SQL joins where required
* Preparing data for Power BI reporting

## Skills Demonstrated

* MySQL
* SQL querying
* Data exploration
* Data filtering
* Data aggregation
* `GROUP BY`
* `ORDER BY`
* SQL joins
* Business data analysis
* Data preparation for Power BI
