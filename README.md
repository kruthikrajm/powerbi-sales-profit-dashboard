# Power BI Sales & Profit Analysis Dashboard

## Project Overview

This project presents an interactive **Sales & Profit Analysis Dashboard** built using Microsoft Power BI. The dashboard provides a clear view of sales performance, profitability, customer activity, product performance, and regional trends.

The project focuses on transforming raw business data into meaningful visual insights that can support data-driven decision-making.

## Objectives

* Analyze overall sales and profit performance
* Identify sales and profit trends over time
* Compare performance across different regions
* Analyze product and category performance
* Understand customer purchasing patterns
* Track key business performance indicators using interactive dashboards

## Tools & Technologies

* **Power BI** – Dashboard development and data visualization
* **SQL** – Data querying and analysis
* **Microsoft Excel** – Data preparation and initial analysis

## Dashboard Pages

### 1. Executive Overview

Provides a high-level summary of business performance using key performance indicators and visualizations.

Key metrics include:

* Total Sales
* Total Profit
* Total Orders
* Total Customers
* Profit Margin
* Sales trends
* Regional performance

### 2. Sales & Profit Analysis

Analyzes sales and profitability across different time periods, regions, and business segments.

### 3. Product Analysis

Provides insights into product and category performance, including high-performing and underperforming products.

### 4. Customer Analysis

Analyzes customer activity and purchasing patterns to identify important customer segments and performance trends.

## Key Features

* Interactive KPI cards
* Sales and profit trend analysis
* Regional performance analysis
* Product and category analysis
* Customer analysis
* Interactive filters and slicers
* Cross-page filtering
* Interactive dashboard navigation
* Data-driven visual reporting

## Project Workflow

1. Data collection and preparation
2. Data cleaning and transformation
3. Data analysis using SQL
4. Data modelling in Power BI
5. Creation of calculated measures
6. Development of interactive visualizations
7. Dashboard design and formatting
8. Cross-page filtering and navigation
9. Final dashboard development

## Project Outcome

The final dashboard provides an interactive view of business performance and allows users to explore sales, profitability, products, customers, and regional trends through filters and interactive visualizations.
